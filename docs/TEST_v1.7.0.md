# v1.7.0 In-Game Test Checklist

Use a **copy** of your world. Remove the older packs, import `Cavira_Craftable_Builds_1.7.0_Lighting_Access_Previews.mcaddon`, and activate both packs.

## 1. Previews
- [ ] Open the tablet and pick a category. Every build button should show a picture.
- [ ] Pick the **Army Barracks**, then **Try It Full Size**. Walk through it, then use the tablet and choose **Remove & Move It**. It should vanish exactly and the outline should come back.
- [ ] Use **Try It Full Size** again and choose **Keep It**.

## 2. Super-Heavy Hangar lighting (the issue you reported)
- [ ] Build it, then set `/time set midnight` and stay a full night cycle. **No mobs should spawn inside.**
- [ ] Walk up the bay stairs and along the mezzanine into every upper bay.
- [ ] Use the side personnel doors.

## 3. Access
- [ ] ATC Tower: climb the spiral stairs from the ground floor to the glass cab.
- [ ] Harbour Control Tower: climb to the cab.
- [ ] Vehicle Depot: take the stairs to the office mezzanine.
- [ ] Radar and dish stations: take the inside stairs to the roof, then the steps up the drum, pyramid or plinth.

## 4. Lighting everywhere
- [ ] At midnight, walk a runway, an apron and any two buildings. No mobs should spawn. The completion message tells you how many lights were added.

## Report back
Send screenshots (the redesigned buildings especially), your device, and any `[CAVIRA]` content-log lines.
