# v1.5.0 In-Game Test Checklist

Use a **copy** of your world. Remove the older Craftable Builds packs, import
`Cavira_Craftable_Builds_1.5.0_Bunkers_Radars_Super_Hangar.mcaddon`, activate both packs, and turn on the same experiments as before.
Note your device (Xbox / iPad / Windows / Realm) next to every result, and screenshot each build.

## Bunkers (Tablet → Bunkers)
For each of the four bunkers: build it on flat ground, then:
- [ ] Walk into the surface entrance hut and down the spiral stairs. You should arrive in the corridor of the bottom floor.
- [ ] On multi-floor bunkers, check the stairs open onto **every** floor.
- [ ] Medium, Large and Strategic: use the glass lift. Jump to climb, sneak to descend, and walk out at each floor.
- [ ] Climb the ladder escape shaft to the surface hatch.
- [ ] Visit every room and check that nothing is floating and the lights work.
- [ ] Strategic only: on the top floor, check the atrium balcony looks down into the command room below.
- [ ] Undo the bunker. Check the terrain is restored, with no holes left in the ground.

## Radars and dishes (Tablet → Strategic / Joint)
- [ ] Build all 9. Check each dish is tilted, with the rim, feed horn and tripod present.
- [ ] Check each radar array is a tilted panel on its pedestal or tower.
- [ ] Walk into each ops building, take the stairs to the upper floor, then up to the roof deck.

## Super-Heavy Aircraft Hangar (Tablet → Air Force)
- [ ] Build it. **Write down roughly how many seconds it takes.** The game should stay responsive.
- [ ] Walk through the door, climb the bay stairs to a mezzanine, and climb the control-room stairs.
- [ ] If you have the Cavira Airforce add-on, fly or taxi the B-2 in through the door and park it in the blue box.

## Report back
Send the device, any failing step, screenshots, and any content-log lines starting with `[CAVIRA]`.
